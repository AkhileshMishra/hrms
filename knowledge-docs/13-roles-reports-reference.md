This comprehensive reference covers role-based access guides, all reports, dashboard charts, print formats, and notification templates.

## Role-Based Guides

### What Can I Do as an Employee?

**Role:** Employee

As an Employee, you have access to self-service features:

#### Personal Information
- View and update your profile (`/app/employee/{your-id}`)
- Update contact information
- View your employment details

#### Leave Management

|--------|--------|
| Apply for leave | Sidebar → Leaves → Leave Application → + Add |

| Request compensatory leave | Sidebar → Leaves → Compensatory Leave Request |

#### Attendance

## Print Formats

### Available Print Formats

| # | Print Format | Document | Description |
|---|--------------|----------|-------------|
| 1 | Standard Salary Slip | Salary Slip | Default payslip format |
| 2 | MOM Compliant Payslip | Salary Slip | Singapore MOM format |
| 3 | Appointment Letter | Appointment Letter | Offer letter format |
| 4 | Experience Letter | Employee | Service certificate |
| 5 | Employee ID Card | Employee | ID card format |

### How to Use Print Formats
1. Open the document (e.g., Salary Slip)
2. Click **Menu** (⋮) → **Print**
3. Select **Print Format** from dropdown
4. Click **Print** or **PDF**

### How to Create Custom Print Format
1. Press `Ctrl + K` → type "Print Format"
2. Click **+ Add Print Format**
3. Enter **Name**
4. Select **Doc Type**
5. Choose **Standard** (Yes for simple, No for custom HTML)
6. Design format using editor
7. Click **Save**

## Notification Templates

### Available Notification Templates

| # | Template | Trigger | Recipients |
|---|----------|---------|------------|
| 1 | Leave Application Approval | Leave submitted | Leave Approver |
| 2 | Leave Status Update | Leave approved/rejected | Employee |
| 3 | Expense Claim Approval | Expense submitted | Expense Approver |
| 4 | Interview Reminder | Before interview | Interviewer |

### How to Configure Notifications
1. Press `Ctrl + K` → type "Notification"
2. Click **+ Add Notification**
3. Enter **Name**
4. Select **Document Type**
5. Select **Event** (New/Submit/Value Change/etc.)
6. Set **Condition** (optional)
7. Configure **Recipients**
8. Enter **Subject** and **Message**
9. Click **Save**

### How to Edit Notification Template
1. Press `Ctrl + K` → type "Notification"
2. Open the notification
3. Edit **Subject** or **Message**
4. Use Jinja variables: `{{ doc.employee_name }}`
5. Click **Save**
